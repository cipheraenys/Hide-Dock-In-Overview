# Security Policy

## Supported versions

Only the latest commit on the default branch is supported. Compatibility with
older GNOME Shell versions is best effort.

## Reporting a vulnerability

GNOME Shell extensions run inside the GNOME Shell process, so a code execution
or privilege issue is worth taking seriously. Please use GitHub private
vulnerability reporting (the Security tab of this repository) instead of opening
a public issue.

Include the GNOME Shell version affected and, if possible, a minimal
reproduction.

Anything that is not a security issue (broken behavior, visual glitches) is
better served by a regular bug report.
